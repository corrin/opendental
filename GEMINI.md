# Gemini Workspace

This file contains project-specific information for the Gemini agent.

## Build Process

To compile the project, run the following command:

```bash
.\build_dev.bat
```

## Area of Responsibility

The primary area of focus for this project is the `.\OpenDentBusiness\ODSMS\` directory. Changes outside of this directory should be minimized.

We are not in charge of, and largely should ignore, any areas outside the ODSMS folder. For example a warning message due to code in some random other folder is not our area and we need to just leave it unless it affects ODSMS. We only modify outside the ODSMS folder when necessary to make ODSMS work.

## Code Summary

A summary of the code in the `OpenDentBusiness/ODSMS` directory can be found in [ODSMS_CODE_SUMMARY.md](OpenDentBusiness/ODSMS/ODSMS_CODE_SUMMARY.md). This file should be kept updated with high-level overviews of what each function does (e.g., if a new function is added or major changes are made to an existing function). Do not include detailed, line-by-line descriptions in `ODSMS_CODE_SUMMARY.md`.
